# HH Industrial Website Project Context


## Company Positioning

Company:
HH Industrial

Business:
Industrial automation solutions and components supplier.


## Target Customers

Primary customers:

- System Integrators (SI)
- Robot Dealers
- Automation Companies
- Machine Builders


## Main Solutions

1. Robot Retrofit Controller

- ABB / KUKA compatible retrofit solutions
- Reduce modernization cost
- Support modern industrial communication


2. Industrial Automation Components

- CNC automation components
- Grippers
- Robot-related accessories


3. Engineering Support

- Application support
- Integration assistance
- Customized solutions


## Website Goal

The website is not an online store.

Main goal:

Generate qualified B2B inquiries from overseas customers.


## Design Direction

Style:

- Industrial
- Professional
- Technology-oriented
- Similar to Siemens / ABB style


Avoid:

- Consumer website style
- Excessive animations
- Generic AI wording


## Development Rules

When modifying the website:

- Keep existing design consistency
- Reuse existing CSS styles
- Prioritize SEO and conversion
- Ensure mobile responsiveness
